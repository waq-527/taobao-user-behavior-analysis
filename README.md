# 淘宝用户行为分析

基于淘宝用户行为日志的电商分析项目，完整走通 **Excel 数据清洗 → SQL 多维分析 → Power BI 可视化 → 分析报告** 流程。围绕“用户从浏览到购买的转化路径”，回答三个问题：整体转化效率如何？流量在时间上有何规律？不同用户与商品类目存在怎样的差异？

## 核心结论速览

| 模块 | 关键发现 |
|---|---|
| 转化漏斗 | 浏览 9,982 → 浏览且收藏加购 7,153 → 三级完成 3,700；浏览→购买 45.94%（用户级），下单/浏览 2.58%（事件级） |
| 时间趋势 | 流量高峰 21~22 点，下单高峰 12~16 点；周末逛多买少（转化 2.30% vs 工作日 2.74%） |
| RFM 分层 | 重要价值 32.1%、待激活 30.4%、重要保持 19.2%、潜力客户 18.3% |
| 复购留存 | 复购率 51.2%（≥2 次）/ 35.5%（≥2 天）；D1~D4 留存 79.2% → 66.6% |
| 商品类目 | 商品 244,220 个、类目 5,091 个；TOP10 商品下单仅占 0.53%，呈长尾分布 |

## 技术栈与能力点

- **Excel**：去重、异常剔除、行为中英文映射、时间戳拆分与标准化
- **SQL Server / T-SQL**：视图口径管理、CASE WHEN 条件统计、CTE 分层查询、窗口函数（LAG / LEAD / ROW_NUMBER / SUM OVER）、自连接 Cohort 留存、DAX 度量值（Power BI）

## 如何复现

1. 数据来源：阿里云天池《淘宝用户购物行为数据集》（UserBehavior，编号 649），链接见 `01 原始数据/数据来源.txt`；本项目使用 UserBehaviorSmall_2017.csv 抽样版
2. 将清洗后的数据导入 SQL Server（表名 `data`）
3. 先运行 `03 SQL脚本/0_新建视图.sql` 建立口径视图
4. 依次运行 `1_数据概览.sql` ~ `7_行为序列分析.sql`
5. 用 Power BI 打开 `04 Power BI看板/淘宝用户行为分析.pbix` 查看可视化

## 数据说明与局限

- 有效分析窗口：2017/11/25 ~ 2017/11/29（5 天，456,889 条行为，10,074 个用户）；11/29 数据仅到 19:00，存在截断
- 数据无商品金额字段，无法计算销售额、客单价与 RFM 的 M 维度，用户分层采用 R+F 二维
- 数据无支付环节，漏斗止于下单
- 行为时间精度为小时，行为先后顺序为近似判断
- 样本为活跃用户抽样，整体渗透率偏高，不代表全量用户水平
