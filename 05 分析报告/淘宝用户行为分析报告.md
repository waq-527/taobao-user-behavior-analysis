# 淘宝用户行为分析项目报告

## 一、项目概述

本项目基于淘宝 2017 年用户行为数据，围绕“用户从浏览到购买的转化路径”展开分析，目标是回答三个问题：用户整体转化效率如何？流量在时间上的分布规律是什么？不同价值用户与商品类目存在怎样的差异？项目完整走通“原始数据清洗 → 指标建模 → 多维度分析”的流程，分析工具为 Excel（数据清洗）与 SQL Server （指标计算），采用 CTE、CASE WHEN、窗口函数（LAG、ROW\_NUMBER）等方法完成漏斗、留存、分层等分析。

## 二、数据说明与处理

### 2.1 数据来源

本报告数据来源于**阿里云天池公开数据集《淘宝用户购物行为数据集》**（UserBehavior，数据集编号 649）：

- 数据链接：https://tianchi.aliyun.com/dataset/649
- 数据说明：淘宝平台用户行为日志，覆盖浏览（pv）、收藏（fav）、加购（cart）、购买（buy）四种行为；原始字段包括用户 ID（user_id）、商品 ID（item_id）、类目 ID（category_id）、行为类型（behavior_type）与行为时间（timestamp）。
- 使用版本：天池抽样数据 UserBehaviorSmall_2017.csv（约 50 万条），其中有效行为记录的时间窗口为 2017/11/25 ~ 2017/11/29。

### 2.2 数据清洗（Excel 基础清洗）

在进入 SQL 分析前，先使用 Excel 完成基础清洗，原始数据约 50 万行，清洗后约 45.7 万行，主要步骤：

1. **导入与结构检查**：导入原始 CSV，核对字段、行数与数据格式；
2. **去重与异常剔除**：删除重复记录，剔除行为时间异常、字段无效的记录；
3. **行为口径加工**：新增“行为名称”列，将行为类型与中文名称一一映射（pv=浏览、fav=收藏、cart=加购、buy=购买），统一分析口径；
4. **时间标准化**：将原始时间戳拆分为“操作日期”与“操作小时”两个字段并统一日期格式，为按天、按小时的分析做准备；
5. **规范输出**：生成含 7 个字段的干净数据表（user_id、item_id、category_id、behavior_type、行为名称、操作日期、操作小时），作为 SQL Server 的分析数据源。

> 清洗后数据仍包含 2017/11/25 之前的 488 条零散记录；进入 SQL 后按 2.3 的有效窗口定义过滤，最终参与分析的行为记录为 456,889 条。

### 2.3 有效窗口的确定

原始数据在 2017/11/25 之前的记录仅 488 条（占 0.1%），且日期分布零散；而 11/25 之后每天记录稳定在 6 万\~10 万条，存在明显数据断层。判定 11/25 之前为测试或异常数据，予以剔除。最终分析窗口定义为 2017/11/25 \~ 2017/11/29（5 天），共 **456,889 条有效行为记录**。

> 说明：11/29 数据仅覆盖至当日 19:00，该日指标对比时需考虑数据截断影响；本项目结论基于 5 天有效窗口，不代表全年特征。

## 三、数据概况

| 指标        | 数值        |
| --------- | --------- |
| 有效行为记录    | 456,889 条 |
| 用户总数      | 10,074 人  |
| 浏览量（pv）   | 405,150 次 |
| 收藏量（fav）  | 14,089 次  |
| 加购量（cart） | 27,216 次  |
| 下单量（buy）  | 10,434 次  |
| 浏览用户人均浏览  | 40.6 次    |

行为结构以浏览为主，浏览、加购、下单的次数比例约为 100 : 6.7 : 2.6。用户平均行为密度较高，属重度活跃用户样本。

## 四、转化漏斗分析

### 4.1 口径定义

漏斗层级为 浏览 → 收藏/加购 → 购买，采用用户去重口径；分析口径未校验行为先后顺序，转化率可能偏高，结论以各级相对流失为主。

### 4.2 用户级漏斗（5 天累计）

| 层级               | 用户数   | 留存率          |
| ---------------- | ----- | ------------ |
| 浏览用户             | 9,982 | —            |
| 浏览且收藏加购          | 7,153 | 71.7%        |
| 浏览→收藏加购→购买（三级完成） | 3,700 | 51.7%（较上一级）  |
| 浏览且购买（含直接购买）     | 4,586 | 45.9%（占浏览用户） |

核心转化率：浏览→收藏加购 **71.66%**；收藏加购→购买 **51.73%**；浏览→购买 **45.94%**。

**主要发现：**

1. **最大流失发生在“收藏加购→购买”环节**：有明确意向（收藏/加购）的用户中，48.3% 最终未下单，说明流失集中在价格、优惠、比价等购买决策环节；
2. **存在直接购买短路径**：从未收藏加购即下单的用户 905 人，占购买用户的 19.5%，其人均浏览仅 23.3 次（整体购买用户为 51.6 次），属于目标明确型用户；
3. 整体渗透率较高与样本为活跃用户有关，不代表全量用户水平。

### 4.3 事件级转化率（流量效率口径）

| 指标              | 数值                        |
| --------------- | ------------------------- |
| 浏览 / 收藏加购 / 下单量 | 405,150 / 41,305 / 10,434 |
| 收藏加购 ÷ 浏览       | 10.19%                    |
| 下单 ÷ 收藏加购       | 25.26%                    |
| 下单 ÷ 浏览         | **2.58%**                 |
| 人均浏览（按浏览用户）     | 40.59 次                   |
| 人均下单（按购买用户）     | 2.25 次                    |

事件级“下单÷浏览”为 2.58%，反映真实流量效率。浏览是高频重复行为（人均 40.6 次），去重后用户级渗透率被大幅放大，故用户级（45.9%）与事件级（2.6%）存在约 18 倍差异，两者口径互补。

### 4.4 单日转化率

| 日期    | 当天浏览用户 | 当天购买用户 | 单日转化率 |
| ----- | ------ | ------ | ----- |
| 11/25 | 7,095  | 1,385  | 19.5% |
| 11/26 | 7,265  | 1,389  | 19.1% |
| 11/27 | 7,151  | 1,476  | 20.6% |
| 11/28 | 7,124  | 1,470  | 20.6% |
| 11/29 | 6,178  | 1,135  | 18.4% |

单日转化率稳定在 18%\~21%，说明转化效率在窗口内较为平稳。

### 4.5 类目级漏斗（维度拆解）

| 类目      | 浏览用户  | 浏览且收藏加购 | 购买用户 | 浏览→购买 |
| ------- | ----- | ------- | ---- | ----- |
| 4756105 | 3,122 | 833     | 66   | 2.1%  |
| 982926  | 2,766 | 628     | 43   | 1.6%  |
| 4145813 | 2,580 | 667     | 77   | 3.0%  |
| 2735466 | 1,680 | 365     | 70   | 4.2%  |

类目间分化明显：4756105 流量最大但转化仅 2.1%，属**流量型类目**（适合引流）；2735466 流量中等但转化达 4.2%，属**转化型类目**（适合促销转化）。

## 五、时间维度分析

### 5.1 按天趋势

| 日期    | UV    | PV     | 收藏    | 加购    | 下单    |
| ----- | ----- | ------ | ----- | ----- | ----- |
| 11/25 | 7,300 | 89,262 | 2,852 | 5,992 | 2,060 |
| 11/26 | 7,472 | 91,010 | 3,235 | 6,022 | 2,080 |
| 11/27 | 7,359 | 83,070 | 2,977 | 5,662 | 2,302 |
| 11/28 | 7,356 | 83,862 | 2,843 | 5,758 | 2,274 |
| 11/29 | 6,401 | 57,946 | 2,182 | 3,782 | 1,718 |

前 4 天流量与成交稳定；11/29 各指标明显下滑，主要原因是该日数据仅覆盖至 19:00（数据截断），并非业务下跌。

### 5.2 按小时分布

- **流量高峰在 21\~22 点**（单小时浏览量 2.8 万以上）；
- **下单高峰在 12\~16 点**（13 点下单 745 单为全天最高）；
- 0 点存在小高峰（下单占全天 3.4%）。

结论：**流量高峰 ≠ 下单高峰**——晚间用户逛得多，日间用户买得更果断。单次浏览的下单效率在 13 点左右（3.3%）显著高于 21 点（2.1%）。

### 5.3 环比与周末效应

- 11/27（周一）浏览量环比下降 8.7%，但下单量环比上升 10.7%；
- 周末（11/25\~26）日均浏览量 90,136，高于工作日（11/27\~28）的 83,466（+8%），但浏览转下单率 2.30% 低于工作日的 2.74%。

结论：**周末逛多买少（休闲型浏览），工作日目的性强（高效成交）**，11/27 的“流量降、下单升”是周末切换工作日的正常结构效应。

## 六、RFM 用户分层

数据不含商品金额字段，无法计算消费金额维度，故采用 **R（最近购买）+ F（购买频率）** 二维分层。

- R：距观察截止日（11/29）最近一次购买的天数，0\~4 天；
- F：5 天窗口内购买次数（平均 2.25 次，中位数 2 次）；
- R 分布：R=0（29 号购买）1,135 人、R=1 1,201 人、R=2 926 人、R=3 738 人、R=4 635 人。

| 用户分层 | 人数    | 占比     | 人均购买商品数 | 业务含义       |
| ---- | ----- | ------ | ------- | ---------- |
| 重要价值 | 1,486 | 32.06% | 3.64 件  | 最近常买，重点维护  |
| 待激活  | 1,411 | 30.44% | 1.00 件  | 降温用户，需召回   |
| 重要保持 | 888   | 19.16% | 2.79 件  | 曾高频购买，需唤醒  |
| 潜力客户 | 850   | 18.34% | 1.00 件  | 近期待转化，引导复购 |

**核心结论**：重要价值用户占 32%，说明样本整体活跃度高；但“待激活 + 重要保持”合计约 49.6%，近一半购买用户处于降温状态，是用户运营的重点发力空间。

## 八、商品与类目分析

### 8.1 数据画像

有效数据涉及商品 244,220 个、类目 5,091 个（出现任一行为即计入）；平均每个商品仅 1.87 条行为（全部行为 456,889 ÷ 商品数 244,220，含浏览/收藏/加购/下单），商品维度高度稀疏。

### 8.2 商品长尾特征

- TOP 10 商品的下单量合计仅占全部下单的 **0.53%**，不存在爆款商品；
- 50% 的下单由 4,378 个商品（占 1.79%）贡献，80% 的下单由 7,509 个商品（占 3.07%）贡献；
- 商品粒度的下单率存在失真（抽样导致“下单/浏览”出现超过 100% 的异常值），因此转化率分析以类目粒度为准。

### 8.3 类目集中度

- 下单最多的 TOP10 类目合计占 13.19% 的下单、21.93% 的浏览；浏览最多的 TOP10 类目合计占 28.21% 的浏览；
- 下单量最高的类目 1464116 下单率 6.33%，类目 2735466 为 3.42%。

**结论**：类目集中度显著高于商品集中度，运营抓手应放在类目层级；商品层级只看“量”，类目层级看“转化”。

## 九、行为路径分析

### 9.1 下单前一步（LAG）

| 下单前一步  | 下单次数 | 占比     |
| ------ | ---- | ------ |
| 浏览     | 7275 | 69.72% |
| 购买（连买） | 1992 | 19.09% |
| 加购     | 529  | 5.07%  |
| 无前序行为  | 395  | 3.79%  |
| 收藏     | 243  | 2.33%  |

### 9.2 浏览后一步（LEAD）

| 浏览后一步 | 浏览次数    | 占比     |
| ----- | ------- | ------ |
| 继续浏览  | 357,921 | 88.34% |
| 加购    | 21,081  | 5.20%  |
| 收藏    | 10,341  | 2.55%  |
| 无后续   | 8,532   | 2.11%  |
| 直接下单  | 7,275   | 1.80%  |

**核心结论**：

1. 69.72% 的下单发生在浏览之后，说明商品详情页（价格、优惠、库存信息）是促成下单的临门一脚；
2. 19.09% 的下单为连续购买（批量购买行为）；
3. 88.34% 的浏览后仍为浏览，用户行为以“逛”为主，单次浏览即时转化率（加购 5.20%、直接下单 1.80%）较低，转化依赖浏览次数的积累。

## 十、核心结论与业务建议

1. **优化“收藏加购→购买”环节**：该环节流失 48.3%，为漏斗最大瓶颈，建议配合购物车召回、限时优惠券、库存紧张提示等运营动作；
2. **重视直接购买人群**：905 名用户未经收藏加购直接下单，决策路径短，建议简化下单流程，避免流程打扰；
3. **分时段运营**：晚间（21\~22 点）适合种草类内容运营，日间（12\~16 点）适合促销转化投放；0 点夜购群体可单独运营；
4. **区分周末与工作日节奏**：周末做浏览型内容（逛），工作日做转化型活动（买）；
5. **召回降温用户**：待激活与重要保持用户合计约占购买用户一半，可结合 RFM 分层进行差异化召回；
6. **以类目为抓手**：商品高度长尾、无爆款，资源应向转化型类目倾斜，流量型类目作为引流入口。

## 十一、分析局限

1. 数据窗口仅 5 天，结论不适用于全年；11/29 数据截断，该日环比需谨慎解读；
2. 数据不含商品金额，无法计算销售额、客单价与 RFM 的 M 维度；
3. 数据不含支付环节，漏斗止于下单；
4. 时间精度为小时，行为先后顺序为近似判断；
5. 商品粒度稀疏，转化率分析仅适用于类目及以上粒度；
6. 样本为活跃用户抽样，整体渗透率偏高，与全量用户水平存在差异。
